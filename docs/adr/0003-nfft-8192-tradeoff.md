# ADR-0003: 包络谱 nfft=8192 而非全长 FFT

日期: 2026-10-12 · 状态: 已采纳(实测推翻"分辨率越高越好"的直觉)

## 背景
rfft(env, 8192) 对 4.8 万点信号会静默截断(只谱前 0.68s)——修成全长 FFT
(分辨率 0.25Hz)后准确率反而 85%→52%。

## 决策
保持 8192。原因: 细分辨率把故障谱线经时基抖动(±1.5%)/幅度调制摊成"裙边",
污染背景窗的指数分布假设, prominence 反而失真。

## 后果
- + 实测各信噪比最优(90/85/75/48%)
- − 频率分辨率止步 1.46Hz; 更低频故障(FTF 谐波)的分辨依赖谐波族而非单线
- − 依赖"粗分辨率=内置平滑"的隐式行为, 注释+本文档防止后人"优化"回去
