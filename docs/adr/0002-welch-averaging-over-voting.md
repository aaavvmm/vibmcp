# ADR-0002: harness 升级用分段谱平均而非投票

日期: 2026-10-12 · 状态: 已采纳(推翻初版投票设计)

## 背景
低置信时需要对冲单次诊断的噪声。初版方案: 切段独立诊断 + 置信度加权多数表决。

## 决策
投票方案实测 -10pp 后推翻。改为 Welch 式分段包络谱平均: 故障谱线在各段
持续存在, 噪声底方差 ~1/K 收紧 —— 低信噪比下"平均证据"才是统计正确的聚合
(投票要求单票准确率>50%, 短段往往达不到, 投票反而放大噪声)。

## 后果
- + 极端噪声(-10dB) +5pp, 其余场景不劣化
- − 引入 Wilson-Hilferty 背景修正的额外复杂度(平均后谱线趋于 Gamma 分布)
- − 谱平均分辨率受段长限制, 见 ADR-0003
