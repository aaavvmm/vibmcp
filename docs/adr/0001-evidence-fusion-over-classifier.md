# ADR-0001: 物理证据融合而非训练分类器

日期: 2026-10-12 · 状态: 已采纳

## 背景
轴承诊断的常规做法是训练分类器(CNN/特征+SVM), 需要 GPU、标注数据、
按工况重训; 且黑盒输出无法向现场工程师解释。

## 决策
采用包络谱物理证据融合: 特征频率谐波族 prominence + BPFI 边带 + 峭度,
加权融合出 verdict+置信度, 证据链逐谐波可溯源。

## 后果
- + 零训练数据、跨工况可迁移、每条结论可解释(现场可核对到具体频带)
- − 精度上限低于训练模型(实测 90% @ +5dB vs CNN ~98%)
- − 阈值经合成信号标定, 真实结构共振漂移依赖 harness 频带搜索兜底
